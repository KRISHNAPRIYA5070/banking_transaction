# Banking Transaction Big Data Analytics

## Project Overview

This project analyzes banking transaction data using Big Data technologies.

## Technologies

- Hadoop HDFS
- MapReduce
- Hive
- Apache Spark
- Python
- GitHub

## Objectives

- Store large banking transaction datasets
- Process transaction data using Hadoop
- Analyze transactions using Hive
- Perform further analytics using Spark
- Identify useful patterns in banking transactions
